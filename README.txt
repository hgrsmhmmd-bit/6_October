عبور النصر — نسخة موحدة

- مفيش شاشة بداية ثانية: زر «ابدأ اللعبة» من الغلاف يدخل مباشرة للعبة.
- زر «تحريك العناصر» أعلى الشاشة يفعّل Nudge/Edit Mode على كل عناصر اللعبة.
- اختاري أي عنصر ظاهر ثم:
  * اسحبيه بالماوس.
  * الأسهم = 1px.
  * Shift + الأسهم = 10px.
  * لوحة العنصر تعرض X / Y / W / H.
- أماكن العناصر تُحفظ تلقائيًا في المتصفح LocalStorage.
- زر «نسخ الإحداثيات» ينسخ Layout JSON لكل اللعبة؛ يمكن إرساله لي لتثبيت الأماكن داخل الكود نفسه.

تشغيل:
افتحي index.html مباشرة. لا يحتاج إنترنت.
